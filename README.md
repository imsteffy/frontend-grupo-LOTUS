# Anime Tracker — Frontend

Aplicación web para el seguimiento y reseñas de anime.

## Descripción

Este repositorio contiene el desarrollo del **frontend** del proyecto Anime Tracker.

La aplicación proporciona la interfaz visual mediante la cual los usuarios pueden explorar anime, gestionar su lista personal, actualizar su progreso, puntuar títulos, escribir reseñas y marcar favoritos.

## Tecnologías

- React
- JavaScript
- HTML
- CSS

## Funcionalidades

- Explorar y buscar anime.
- Consultar información detallada.
- Gestionar la lista personal.
- Actualizar estado y progreso.
- Puntuar anime.
- Crear y consultar reseñas.
- Gestionar favoritos.
- Consultar historial y estadísticas.
- Filtrar y ordenar contenido.

## Integración

El frontend consume los servicios proporcionados por la **API REST desarrollada en el repositorio de backend**, mediante peticiones HTTP y respuestas en formato JSON.
